Sprint7-final-project

Este repositorio contiene el análisis realizado durante el sprint 7. - Análisis de una empresa de telecomunicaciones.

Se analizo y evaluo el comportamiento de los clientes de una empresa de telecomunicaciones en Latinoamérica, ConnectaTel.

📂 Contenido del repositorio
notebooks/telecom-analysis.ipynb -> Notebook principal con limpieza, eda, distribuciones, outliers.

🧠 Objetivo del análisis
Identificar problemas de calidad de datos
Analizar comportamientos, distribuciones y outliers
Identificar patrones de consumo
Generar insights para diseñar estrategias de retención.
